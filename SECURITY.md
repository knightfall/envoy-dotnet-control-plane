# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately using [GitHub's private vulnerability reporting](https://github.com/knightfall/envoy-dotnet-control-plane/security/advisories/new). Do not include vulnerability details in public issues or pull requests. Include affected versions, steps to reproduce, potential impact, and any relevant configuration. Maintainers will review reports and coordinate disclosure and any remediation through the private advisory.

## Supported versions

This project is prerelease software. Include the package version and source revision in your report; maintainers will assess affected versions and available fixes on a case-by-case basis.
