# 1.0.0-rc.2

Second release candidate for all five `Knightfall.Envoy.ControlPlane` packages. The packages continue to target .NET 10 and retain their package IDs, assembly names, C# namespaces and protobuf identities.

## Runtime improvements since 1.0.0-rc.1

- **Delta discovery.** SnapshotCache and LinearCache drain queued responses before replacing a watch so removals reach the client in order. Established streams resend explicitly requested resources even when their versions match. ACKs without subscription changes stay quiet, and reconnects still honor initial resource versions. (#113, #114)
- **SnapshotCache.** Wildcard fan-out reuses immutable serialized payloads and version data across subscribers. Snapshot publication and heartbeat delivery are coordinated per cache key, so a blocked watch on one key no longer holds up delivery for another. (#132, #133)
- **Cache lifecycle and hosting.** Watch responses are delivered outside cache state locks, and watches can be disposed during delivery. LinearCache rejects invalid update names before changing resources or versions. In-flight HTTP Fetch work is cancelled when the ASP.NET Core host stops. (#115)
- **Optional validation.** The validator adds evaluators to its cache only after the complete dependency graph compiles, including recursive types. Preloading traverses nested declarations and rejects unmigrated PGV metadata at startup. (#115)
- **Package dependencies.** gRPC moves to 2.85.0, and the optional validator's `Microsoft.Extensions.Options` dependency moves to 11.0.0. (#104, #96)

## Verification and documentation

- **Live Envoy coverage.** Docker integration tests on Linux amd64 and arm64 cover SotW and Delta discovery, REST polling, MuxCache, TLS and mTLS, node authorization, SDS certificate rotation, fleet isolation and validated publication. Containerized smoke tests exercise the example and a consumer restored from freshly packed NuGet packages. (#124, #126–#131)
- **Release and contributor guidance.** The repository adds a package signature and provenance verification guide, candidate checks for package README links and packed README contents, and guidance for live snapshot replacement, rollback, resource withdrawal and custom resource types. The Go verification toolchain and its dependencies were updated for security advisories. (#87, #93, #134, #135)

All five packages ship together. To update, use `1.0.0-rc.2` for each `Knightfall.Envoy.ControlPlane` package your application references directly.
