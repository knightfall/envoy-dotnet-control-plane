# 1.0.0-rc.3

This release candidate ships all five `Knightfall.Envoy.ControlPlane` packages for .NET 10.

## Runtime changes

- Dedicated SotW and Delta RPCs accept the service's own type explicitly or implicitly. ADS still accepts application-defined resource types, with a configurable limit of 64 distinct types per stream by default.
- Dedicated and ADS Delta streams bound retained subscription names, prefixes, pending wildcard resets, and client-supplied version map keys and values with configurable entry and character limits.
- SnapshotCache releases the status of an unpublished node when its last pending watch ends.
- Unexpected SotW, Delta, and unary Fetch failures return fixed gRPC status details while the host logs the exception. Stream cleanup failures preserve the primary status.
- The optional HTTP Fetch gateway limits request bodies to 1 MiB by default and preserves status codes from host body-read errors. It handles concurrent failures during shutdown with the same response policy as cancellation.
- The optional validator uses managed RE2-compatible matching for the pinned Envoy patterns and the predefined header and UUID patterns. Applications can require those patterns with `RequireCatalogRegexPatterns`. Other patterns retain .NET semantics and a match timeout by default. See the [validation package scope](../../src/Envoy.ControlPlane.Validation/README.md).

## Release verification

Each post-publication consumer checks the original manifest digest and the complete candidate. It verifies resolved third-party dependency versions and hashes against the sealed runtime dependency locks before running packages from its registry.

Use `1.0.0-rc.3` for each `Knightfall.Envoy.ControlPlane` package your application references directly. [Verify a published package](VERIFYING.md)
