# Retained research scripts

Maintained repository commands now live in the [project-based tooling](../tools/README.md). Use that command map for source verification, generation, validation and package-consumption proof.

`validation/ValidationAssessment.cs` and `validation/ValidationMigration.cs` preserve earlier provider-assessment orchestration. They are historical source, excluded from active tooling projects and CI. Their old entry points are no longer available, and their original paths and command references describe the historical experiment.

The related published-package probes remain under [tests/validation/](../tests/validation/README.md). Cleanup of that research remains deferred.
